1. 角度和弧度表示的概念一样，当代码中需要旋转节点的时候，这两种单位都可以使用。
2. 当圆弧的长度刚好等于圆的半径时，这个角度就叫 1 弧度
3. PI = 圆的周长 / 圆的直径
4. 根据第二条和第三条可以得出结论（r表示半径）：
    - 圆的周长 = PI * r * 2
    - 完整一圈的弧度数 =  PI * r * 2 / r = 2 * PI
    - 半圈的弧度数 = 2 * PI / 2 = PI
    - 弧长 = 弧度数 * r
5. 向量指的是有大小和方向的量。
    - 比如：Vector2(0, -1) 在 godot 中可以表示一个向上，长度为1的向量，但是也可以表示成速度，向上每秒移动1个单位。
    - 如果一个向量被看成方向，那么这个向量可以通过乘以一个值来表示速度，比如 Vector2(0, -1) * 10 表示向上每秒移动10个单位。
